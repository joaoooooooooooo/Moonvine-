# Next Steps Section

Accepts NextStepsData with stable action IDs and a separate heading. The report provider resolves the {company} placeholder in intro copy. No database connection.

Reuses NextStepsIntro (Artboard), ReportHeading, ReportSection and ActionCard. Cards use one column on mobile, two on tablet and three on desktop. The shared artwork preserves its in-view animation and bottom fade; section dividers follow ReportSection.
